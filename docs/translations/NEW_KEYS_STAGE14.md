# Keys added in stage 1.4 (untranslated rejections and errors)

Machine translation, **not yet read by a native speaker**. Digits and the rupee sign are not used. English shows the backend's own text for these messages; the other five languages show these keys. `rejected.orderOffer` (stage 1.3) is listed in `NEW_KEYS_STAGE1.md`.

Mapping: `rejected.notAScreen` is shown for `screen_type: other` when `needs_review` is false (the model judged it is not a trip or payout screen). The `errors.*` keys are shown for the backend `error_code` values `unreadable_image`, `no_trips`, `no_weeks`, `costs_not_set` and `daily_limit_reached` (`daily_limit_reached` used to show the 'busy, try in a minute' text).
