PayProof helps gig workers check what they really earn. A worker uploads earnings screenshots; Gemini 3.1 Flash-Lite on Vertex AI reads them into a table the worker checks against their own screenshot and confirms. A deterministic Python engine, not the model, computes net pay after the worker's own costs, pay per hour, pay per km and the platform's deduction share. Gemini explains results through function calling; a verifier blocks any number the engine did not produce. Unreadable screens are rejected or left blank. Firebase Hosting serves the web app, Firebase Authentication signs users in anonymously, Cloud Run runs the FastAPI backend, and Firestore stores only confirmed data. Screenshots are never stored; users can delete their data. The interface is available in five Indian languages (machine-translated, awaiting review) with voice input. On 50 simulated screenshots: 171 of 172 fields correct on 30 clean ones (1 unflagged blank); on 10 unreadable ones, none shown as confidently wrong.
